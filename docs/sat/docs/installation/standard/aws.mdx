# AWS Installation

This guide will walk you through setting up the **Security Analysis Tool (SAT)** on AWS Databricks.

<Admonition type="warning" title="Unity Catalog Required">
**SAT requires Unity Catalog.** Make sure Unity Catalog is enabled in your Databricks environment before installing SAT.
</Admonition>

<Admonition type="info" title="AWS GovCloud & DoD Support">
SAT supports **AWS GovCloud** (FedRAMP) and **AWS DoD IL5** — it resolves the correct account-console host for each (`accounts.cloud.databricks.us` for GovCloud, `accounts-dod.cloud.databricks.mil` for DoD). On GovCloud/DoD, use classic compute for cross-workspace collection.
</Admonition>

<Admonition type="tip" title="Best for Premium & Enterprise Tiers">
SAT is especially beneficial to customers on Databricks **Premium** or **Enterprise** tiers, where Unity Catalog and the richer access controls SAT analyzes are available.
</Admonition>

## Prerequisites

Before you begin, ensure you have:

- ✅ Reviewed the [general prerequisites](../../installation/index.mdx#prerequisites)
- ✅ Appropriate permissions in your Databricks Account Console
- ✅ A metastore attached to your installation workspace
- ✅ Databricks CLI installed and configured
- ✅ **Python 3.9 or higher** (3.9–3.12, for running the local installer)

## Step 1: Create Service Principal

The Service Principal allows SAT to authenticate with your Databricks workspaces and collect security information.

<AccordionItem question="How to create a Service Principal">

**Follow these steps in the Databricks Account Console:**

1. Navigate to the [Account Console](https://accounts.cloud.databricks.com)
2. Click on `User management` in the left sidebar
3. Select `Service Principal` → `Add service principal`
4. Enter a name for the service principal (e.g., "SAT-Service-Principal")
5. Grant the `Account Admin` role
6. Assign the `Workspace Admin` role for each workspace to be monitored
7. Add to the `Metastore Admin` group or role
8. Create a new OAuth Secret
9. **Save the `Secret` and `Client ID`** (you'll need these later)
10. Add the Service Principal to each workspace you want to analyze

  <img src={useBaseUrl('/img/aws_ws.png')} alt="Service Principal Setup" />

**Required Permissions:**
- [Account Admin role](https://docs.databricks.com/aws/en/admin/users-groups/service-principals)
- [Workspace Admin role](https://docs.databricks.com/aws/en/admin/users-groups/service-principals) for **each workspace**
- [Metastore admin group](https://docs.databricks.com/aws/en/data-governance/unity-catalog/manage-privileges/admin-privileges) membership

</AccordionItem>

## Step 2: Run Installation

<Admonition type="note" title="Credentials Required">
Have these ready for the app's **in-app setup** (you enter them in the app after install, not during `install.sh`):

- 🔑 **Databricks Account ID**
- 🔑 **Databricks Service Principal ID** (Client ID from Step 1)
- 🔑 **Databricks Service Principal Secret** (from Step 1)
</Admonition>

### Installation Steps

Run these commands on your workstation or a VM with internet access and Databricks workspace connectivity:

**1. Clone the SAT repository:**

```sh
git clone https://github.com/databricks-industry-solutions/security-analysis-tool.git
cd security-analysis-tool
```

<Admonition type="warning" title="Databricks CLI Required">
Make sure the target workspace has a [profile configured](https://docs.databricks.com/aws/en/dev-tools/cli/profiles) in the [Databricks CLI](https://docs.databricks.com/aws/en/dev-tools/cli/tutorial).
</Admonition>

**2. Make the installation script executable and run it:**

```sh
chmod +x install.sh
./install.sh
```

<Admonition type="tip" title="Proxy Support">
**Proxies are supported!** You can add your HTTP and HTTPS proxy values during the install.sh script when prompted.
</Admonition>

**3. Follow the interactive prompts:**

The installation script will guide you through the setup process. Here's what it looks like:

<Admonition type="note" title="Finish setup in the app">
After `install.sh` deploys the app, open it (**Compute → Apps → security-analysis**) and complete the in-app setup — results catalog/schema, SQL warehouse, and (optionally) account credentials for account-wide data. Permissions Analysis is built into the app; there is no separate app to configure.
</Admonition>

<Admonition type="tip" title="Scanning multiple workspaces">
To cover more than the workspace SAT is installed in, add the SAT service principal as a **workspace admin** on each workspace you want scanned, then in the app open **Data Collection → Manage**, set **Compute & scope** to **Multiple workspaces** (switching to Multiple runs a workspace sync for you), and confirm the panel's "Will scan: N workspaces" count. Use **Manage → Sync workspaces** any time you later add or remove the service principal as an admin. See the [usage guide](../../usage.mdx) for the full workflow.
</Admonition>

Congratulations! 🎉 You've successfully installed SAT on AWS Databricks.

</Admonition>
