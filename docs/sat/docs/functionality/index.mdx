# Functionality

The **Security Analysis Tool (SAT)** is a security-posture app for Databricks. It helps you see **who can access what** across your account — and where that access is risky — and find **hardcoded secrets** exposed in notebook source and cluster configurations, all from a single Databricks App.

<Admonition type="tip" title="What's new in 1.0">

- **One Databricks App** — setup, data collection, permissions analysis, secret scanning, alerts, and the security assistant are now a single app.
- **In-app setup & job provisioning** — pick your catalog/schema and warehouse in the app; it creates and schedules its own collection jobs. No notebooks to import.
- **In-app controls** — set scan scope, serverless vs. classic compute, notebook/folder collection, and secret-scan coverage and custom detection rules, all from the UI.
- **Per-user authorization (OBO)** — queries run as the signed-in user, so Unity Catalog enforces each viewer's grants. Alert management is restricted to admins.
- **Retired** — the core security posture checks are now native in the [Databricks Governance Hub Security tab](https://docs.databricks.com/aws/en/admin/governance-hub/security), so they, the classic dashboards (General and Executive), and the Initializer/Driver notebook workflow are no longer part of SAT. See the [Upgrade Guide](../upgrade).

</Admonition>

## How SAT Works

The app provisions its own collection jobs and runs them on a schedule (you can also run them on demand):

* **Data Collection**  
  The collection jobs query Databricks account and workspace APIs to build a graph of your identities, resources, and permission relationships, and scan notebook source and cluster configurations for exposed secrets.

* **Historical Tracking**  
  Results persist in Delta tables in your chosen Unity Catalog schema, for historical tracking and trend analysis.

* **In-app Reporting**  
  You explore everything in the app — as the signed-in user, so Unity Catalog enforces your own grants on what you can see. No separate dashboard to publish or share.
