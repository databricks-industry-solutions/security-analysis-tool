# Overview

**Security Analysis Tool (SAT)** is a security-posture app for Databricks. It reveals **who can access what** across your account — and where that access is risky — and finds **hardcoded secrets** exposed in notebook source and cluster configurations.

<Admonition type="tip" title="SAT Capabilities">
SAT builds a queryable graph of your identities, resources, and permissions across your Databricks workspaces on **AWS**, **Azure**, and **GCP**, and scans notebooks and cluster configurations for exposed credentials — surfacing access risk and secret exposure in one app.
</Admonition>

## What SAT Analyzes

SAT focuses on access and secret exposure:

- **👥 Identities & Access** - Users, groups, and service principals; admin roles (Account / Workspace / Metastore Admin, Catalog Owner); and the full access graph, including access inherited through groups.
- **🗄️ Resource Access** - Who can reach catalogs, schemas, tables, clusters, jobs, warehouses, secret scopes, notebooks, and folders.
- **🧭 Escalation & Impersonation** - Paths from any principal to admin roles, and lateral movement via jobs or clusters that run as elevated service principals.
- **🔑 Exposed Secrets** - Hardcoded credentials in notebook source and cluster configurations.

<Admonition type="note" title="Best-practice checks retired">
Earlier versions of SAT also ran core security posture checks (severity-ranked findings across Network Security, Data Protection, Governance, and so on) and rendered them in dashboards. Those checks are now available **natively in the Databricks platform** — the [Governance Hub Security tab](https://docs.databricks.com/aws/en/admin/governance-hub/security) — so they and the dashboards are **retired** from SAT; 1.0 focuses on the capabilities Governance Hub doesn't cover: access/permissions risk and secret exposure. (If Governance Hub isn't available in your environment, e.g. AWS GovCloud, use SAT v0.9.1 for the checks.)
</Admonition>

## Important Considerations

<Admonition type="warning" title="Assessment Tool">
SAT is a **productivity tool** that helps you understand access risk and find exposed secrets across your Databricks account. It is *not* intended to serve as a certification or formal attestation of your deployment's security posture.
</Admonition>

### Before Making Changes

Please review the SAT report with your:
- ✓ Business stakeholders
- ✓ System administrators  
- ✓ Security team
- ✓ Compliance auditors

**Key points to consider:**
- 📌 Not every finding requires immediate action
- 💰 Some recommendations may have cost implications
- 🔗 Some security features may have dependency limitations
- 📖 Always review the associated documentation before making changes
